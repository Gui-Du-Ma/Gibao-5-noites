# 🐔 Gibão — As Cinco Noites

## Sobre o projeto

INTEGRANTES: Guilherme Duarte, Rafael Gomes e Nicolas Silva

Gibão — As Cinco Noites é uma visual novel de terror desenvolvida em Python.

O jogo conta a história de Bob, um homem que vive sozinho no interior e começa a perceber acontecimentos estranhos envolvendo suas galinhas e seu vizinho Rafael.

A história é dividida em cinco noites e apresenta uma narrativa linear, na qual o jogador acompanha diálogos, cenas e acontecimentos apenas avançando a história.

O objetivo do projeto é desenvolver uma experiência curta de terror focada em narrativa, suspense e reviravoltas.

## Como executar

### Requisitos

- Python 3.x

Clone o repositório:

-git clone https://github.com/Gui-Du-Ma/Gibao-5-noites.git

Entre na pasta do projeto:

-cd O-vizinho-Estranho

Instale a biblioteca necessária:


-pip install pygame

Execute o jogo:

-python main.py

## Controles

- **Enter ou Espaço:** avançar os diálogos.
- **Mouse:** avançar os diálogos.
- **Esc:** fechar o jogo.

## Recursos do jogo

- Diálogos com texto aparecendo gradualmente.
- Personagens e cenários ilustrados.
- Animações durante algumas cenas.
- Efeitos sonoros e música de fundo.
- Transições entre as cenas.
- Momentos de suspense com efeitos visuais.

## Estrutura do projeto

Os arquivos do jogo são organizados entre o código principal e os recursos utilizados durante a execução, como imagens e sons.

- `main.py`: código principal do jogo.
- `assets/`: pasta destinada às imagens, sons e outros recursos utilizados pelo jogo.

## Tecnologias utilizadas

- **Python:** linguagem de programação utilizada no desenvolvimento.
- **Pygame:** biblioteca utilizada para criar a janela do jogo, exibir imagens, reproduzir sons e controlar os eventos.

## Observações

O jogo é um projeto independente, desenvolvido com foco em programação e narrativa interativa.

A história é linear, então as escolhas do jogador não alteram o rumo dos acontecimentos. O jogador acompanha a história avançando pelos diálogos.
